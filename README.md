# Portfolio

Personal portfolio of Kamil ([@blokzz](https://github.com/blokzz)): a single-page, dark, minimal site built with Next.js, TypeScript and Tailwind CSS.

## Editing content

All text lives in [`src/data.ts`](src/data.ts): profile, projects, stack and facts. Layout is in [`src/app/page.tsx`](src/app/page.tsx), colors in [`src/app/globals.css`](src/app/globals.css).

## Development

```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # production build
npm run lint
```

Deployed on Vercel.
